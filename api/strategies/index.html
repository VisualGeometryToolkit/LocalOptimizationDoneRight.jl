Local optimization strategies

Every strategy implements VisualGeometryCore's local-optimization contract (lo_workspace, locally_optimize!), so it composes with any scorer in RobustVisualGeometry's ransac and find_* pipelines. The core baselines, NoLocalOptimization and Irls{K}, live in RobustVisualGeometry. A width-carrying strategy takes scale_multiple = m (a multiple of the consensus set's scale), loss_width = w (an absolute width), or neither, in which case its loss width follows the scorer's inlier threshold. See the Overview.

Half-quadratic lifts and graduated non-convexity

LocalOptimizationDoneRight.HQ — Type
HQ{K<:AbstractLossShape} <: AbstractLocalOptimization

Half-quadratic lifted local optimization on loss K (Zach 2014): the genuine joint-(θ,z) Gauss-Newton on the lifted residual (zᵢ·rᵢ, κ(zᵢ²)) with the loss's closed-form Geman–Reynolds regularizer (lift_zblock, VGC's loss family). Per-point weight zᵢ is a free variable, initialized LARGE (all-inlier = smoothed cost) and evolved jointly with θ, Schur-eliminating Δz — this broadens the basin, escaping a poor seed where the static Irls/StudentTUniform is trapped, without annealing or quadrature. ONE code path for every loss AND every problem (ManifoldLiftHQ on VisualGeometryCore's chart-rows contract, lift/lifts.jl); K contributes only its closed-form z-block quantities and tracked cost. Implemented for every liftable problem (the MinimalSolveProblem family: its lift provider supplies the chart).

The loss width is frozen at setup by the width mode (VisualGeometryCore's loss_at): at the consensus set's Student-t scale ŝ the scale_multiple is read in the loss's OWN currency (RobustVisualGeometry's plain_scale_multiple, shared with Irls{K}), which converts it to the plain multiple that goes in a deployment's scale_multiple slot — the loss width is then scale_multiple·ŝ and sq_loss_width is scale_multiple²·ŝ², with the multiple and the noise variance stored apart and never multiplied into a stored width:

  • K = WelschShape: loss_width = scale_multiple·ŝ (1.5 was the pre-anchoring point)
  • K = SmoothTLSShape: hard cutoff loss_width = scale_multiple·ŝ (historically 2.0 = the statistically natural 2σ cutoff; no width follows the scorer's decision point). Default max_iter = 40 (historical ψ̂ arm).
  • K ∈ {GemanMcclureShape, CauchyShape}: the shared half-weight ablation currency loss_width = decision_width(K(), scale_multiple·ŝ) (historically 1.5·√ln2 — the deployed Welsch arm's evidence depth). NOTE the roster's GM arm keeps its CONSTRUCTOR-level convention scale_multiple = κ·√ln2 (κ the shared Welsch grid value).

Fields

  • max_iter::Int: max joint-GN iterations (25; 40 for SmoothTLSShape)
  • μ::Float64=1e-9: Gauss-Newton damping
  • init::Symbol=:flat: z₀ policy — :flat (all-in, default) | :posterior (soft seed weights) | :consensus (hard r½ mask)
  • width::W: the width mode (scale_multiple = m in the per-K currency above, loss_width = w, or neither: follow the scorer), as Irls

LocalOptimizationDoneRight.WelschHQNewton — Type
WelschHQNewton(; scale_multiple, max_iter=25, μ=1e-9)

Welsch half-quadratic lift refined with the convexified Newton joint-(θ,z) step (Zach & Bourmaud, ECCV 2018, Eq. 15) instead of the Gauss-Newton step of HQ{WelschShape}. Identical fixed-scale setup (loss_width = scale_multiple·ŝ from the seed partition); the only difference is the second-order z-block with the convexification h_z = max(2r² + 4·loss_width²·(1+ln z), 8r²). Intended as the A/B partner of the GN lift — it should match on easy seeds and (per the paper) reach better minima on hard, barrier-crossing seeds. EssentialProblem only.

source
LocalOptimizationDoneRight.WelschHQEcm — Type
WelschHQEcm <: AbstractLocalOptimization

Ablation sibling of HQ{WelschShape}: the same closed-form Welsch joint-(θ,z) lift, but the loss width scale_multiple·√ŝ² is re-estimated each iteration by the same Student-t + uniform ECM the mixture uses (_mix_ecm), instead of fixed at the seed. Closed-form κ² ⇒ no LUT, so the only added cost is the O(n) ECM sweep. Kept a separate LO strategy so fixed-vs-ECM scale can be ablated head-to-head.

Fields

  • max_iter::Int=25: max joint-GN iterations
  • scale_multiple::Float64: the loss width as a multiple of ŝ (scale_multiple·√ŝ², ŝ² re-estimated per iter)
  • μ::Float64=1e-9: Gauss-Newton damping

LocalOptimizationDoneRight.BarronHQ — Type
BarronHQ(α; scale_multiple, max_iter=25, μ=1e-9)

The α-DIAL lift (smooth-and-lift 3-ii): the same genuine joint-(θ,z) half-quadratic lift as HQ with the Barron family loss at fixed shape α, standardized in the FIXED-CORE-WIDTH currency — the facet-B Barron loss width is scalemultiple·ŝ/√2, which holds the near-zero (Gaussian-core) curvature IDENTICAL across every α, so the dial isolates tail steepness (retirement profile) only. Anchor identities (mandatory gates, liftlossestests.jl): α → −∞ runs the SAME iteration as `HQ{WelschShape}(; scalemultiple)`; α = −2 matches the GM lift and α = 0 the Cauchy lift at their convention-mapped scales. Runs on the generic ManifoldLiftHQ driver, so on every liftable problem.

LocalOptimizationDoneRight.Gnc — Type
Gnc{S<:AbstractLocalOptimization} <: AbstractLocalOptimization

Graduated-non-convexity WRAPPER: canonical Yang–Carlone GNC (RA-L 2020) with the Black–Rangarajan surrogate weights, graduating the objective of the wrapped static strategy S — the paper's three GNC baselines for the continuation family:

  • Gnc{Irls{WelschShape}} — GNC-W (annealed-width Welsch)
  • Gnc{Irls{TLSShape}} — GNC-TLS (Black–Rangarajan band surrogate of the HARD truncation; TLSShape is the hard-TLS facet tag of VGC's loss family)
  • Gnc{Irls{GemanMcclureShape}} — GNC-GM (μ-convexified GM)

The type parameter ADMITS any strategy (Gnc{HQ{K}} — graduation OVER the lift, a composite :gnc ∘ :hq mechanism — and the Resample{S} wrapper are NOT implemented here, the LO dispatch covers Gnc{<:Irls} only). The GNC arms run through the same locally_optimize! contract as every IRLS/lift strategy — one code path, one width resolution.

Width (VisualGeometryCore's loss_at): under ScaleMultiple(m) the terminal (target) loss width is c̄ = m·ŝ with ŝ the consensus set's Student-t scale (exactly the width the lifted loss arms freeze); under LossWidth(w) it is w; with neither it follows the scorer's inlier threshold. There is no plug-in scale bootstrap.

Variants and μ-schedules:

  • :gm (GNC-GM) — surrogate ρμ(r) = μc̄²r²/(μc̄² + r²), weights `w = (μc̄²/(r² + μc̄²))² ≡ liftweight(GM, r², μ·c̄²)`; μ₀ = 2·r²_max/c̄² (convex start from the SEED residual extreme), μ ← μ/factor per rung, clamp at μ = 1 (true GM) and spend the remaining budget there.
  • :welsch (GNC-W) — annealed-WIDTH Welsch, c²μ = μ·c̄², weights w = exp(−r²/(μc̄²)); μ₀ = r²max/c̄² (every seed point starts ≥ e^{−1}) or a numeric entry = m ⇒ μ₀ = max(m², 1) (entry-breadth dose axis), μ ← μ/factor, clamp at μ = 1 (target Welsch at c̄).
  • :tls (GNC-TLS) — piecewise Black–Rangarajan band weights (gnc_tls_weight); μ₀ = c̄²/(2r²max − c̄²) with the r²max ≤ c̄²/2 guard (⇒ skip graduation, start effectively-hard), μ ← factor·μ, stop graduating once the middle band is empty or μ ≥ 1e6, then finish at the terminal surrogate.

Budget parity: TOTAL model updates across ALL rungs = max_iter (the shared 25-update LO cap; every GNC stage counts). Rung arithmetic is VGC MuLadder (budget = :converged ⇒ converged-rung mode, max_iter a safety ceiling). Rung advance is scheduled OR stall-early; termination is TERMINAL-only (the 373d0a6 semantics via the LoSchedule trait). Best-tracking is on the TARGET loss (true TLS cost / true GM ρ / fixed-width Welsch cost at c̄) — graduation shapes exploration only. Implemented for every liftable problem (the MinimalSolveProblem family), like HQ{K}.

Student-t + uniform and Barron-adaptive strategies

LocalOptimizationDoneRight.StudentTUniform — Type
StudentTUniform <: AbstractLocalOptimization

The paper's Stu-tU-IRLS: posterior-weighted IRLS under the Student-t + uniform mixture (the same model family as the profile-marginal score). Computes posterior inlier probabilities from the marginal score partition, uses them as soft weights for a WLS refit, re-scores, and iterates over a fixed Student-t + uniform likelihood. Self-scaling: it re-estimates its own scale each iteration (contrast with the consensus-anchored Irls{K}/HQ{K}/ Gnc{S} strategies, whose loss width is frozen at scale_multiple·ŝ from the consensus set).

It needs the scorer's uniform outlier model (outlier_halfwidth).

Fields

  • max_iter::Int=5: Max IRLS iterations per hypothesis
source
LocalOptimizationDoneRight.StuTuBCD — Type
StuTuBCD <: AbstractLocalOptimization

Exact same-objective refinement for StudentTUniformScoring: block-coordinate ascent on the scoring objective S itself. Alternates

(model) θ⁺ = argminθ Σ{i∈I} rᵢ(θ)² — hard-inlier least squares (partition) I⁺ = argmax_I S(θ⁺, I) — the score's own sort-and-sweep

to convergence. Every step is non-decreasing in S: the model step lowers RSS_I with all other score terms fixed (so S rises), and the partition step is the score's exact argmax over partitions. Unlike StudentTUniform (soft, score-derived responsibilities under a related t/uniform mixture — NOT the Jeffreys-collapsed hard-partition objective) and the Welsch-HQ lift (a different objective optimized jointly over auxiliary weights), this is the strict same-objective' baseline: exact score monotonicity, hard partition. Expected to be very monotone but narrow-basined — correspondences excluded by the current partition exert no force on the pose (RSS_I` sees only I).

Fields

  • max_iter::Int=25: max block-coordinate sweeps per hypothesis
  • tol::Float64=0.0: minimum score increase to keep iterating
source
LocalOptimizationDoneRight.StuTuHQTabulated — Type
StuTuHQTabulated <: AbstractLocalOptimization

Half-quadratic lifted LO using the exact Student-t + uniform mixture loss ρ(r)=−log(π_in t_ν(r;ŝ²)+π_out(2a)^{−d}). Same genuine joint-(θ,z) weight-lift as HQ{WelschShape}, but the regularizer κ² — whose closed form is transcendental for the mixture — is tabulated per ECM iteration: the monotone weight ω=u·w_resp is inverted on a grid (r²(w)=−κ²′(w)) and cumulatively integrated (κ²(w)). Scale ŝ² and mixing π_in are ECM/EM-updated each iteration. EssentialProblem only.

The lifting-regularizer strength γ scales the down-weighting penalty κ² (a GNC-style continuation knob): γ>1 makes the lift more reluctant to switch points off (softer z-block Hessian, hreg ∝ 1/γ), keeping it in a smoother, wider-basin regime for better escape from a poor seed. Selection is always on the true γ=1 objective (best-tracking), so γ shapes only the exploration — hence a constant, validated γ (rather than a schedule). κ² is built on a fine grid so γ is the sole, explicit regularizer knob. On PT val the LO is insensitive to γ over [1,5] (median 4.92–5.04°, within the basin-flip noise); γ=2.5 is the robust plateau choice (near the per-scene minima, non-edge).

Fields

  • max_iter::Int=25: max joint-GN iterations
  • γ::Float64=2.5: lifting-regularizer strength (PT-val plateau; LO is γ-insensitive over [1,5])
  • μ::Float64=1e-9: Gauss-Newton damping
  • lut_points::Int=32: κ² grid resolution. The table is read by cubic Hermite interpolation using the exact node slopes κ²′=−r² (the stationarity condition), so 32 nodes match a ~1000-node linear table in accuracy at ~⅛ the per-iteration rebuild cost. γ remains the sole regularizer knob — grid coarseness is no longer an accuracy lever (the inflation trap of a coarse linear table is avoided).
source
LocalOptimizationDoneRight.StuTuRegemm — Type
StuTuRegemm <: AbstractLocalOptimization

Half-quadratic LO for the same Student-t + uniform mixture loss as StuTuHQTabulated, but solved by relaxed generalized majorization-minimization (ReGeMM; Zach & Le, ECCV 2020, §6.1) instead of the joint weight-lift. Faithful to the paper's robust-estimation scheme: weights are initialized all-inlier (u≡1) and inferred inexactly by graduated non-convexity. Each round (i) ECM-updates ŝ²,π_in and rebuilds the κ² table, (ii) sets uᵢ = ω(rᵢ/σ) — the touching weight at an inflated scale σ≥1, with σ the largest value (by bisection) still meeting the diminishing-gap criterion J(θ,uⁿᵉʷ) ≤ η·J(θ) + (1−η)·J(θ,uᵒˡᵈ), J(θ)=minₚ J(θ,u), then (iii) minimizes the bound over the pose for the graduated weights (the weighted-Sampson refit, Alg. 1's line-3 argmin), accepted only if it descends. σ anneals to 1 as the gap tightens, so this is weight-space GNC from the smooth init.

The monotone, convergent counterpart of the StuTuHQTabulated joint step. Zach & Le report it favorable vs the joint HQ lift on bundle adjustment (truncated quadratic); on 2-view essential the joint lift reaches a better optimum with a lighter tail. EssentialProblem only.

Fields

  • max_iter::Int=100: number of ReGeMM rounds (one σ-graduation + one pose refit each)
  • η::Float64=0.5: diminishing-gap fraction (Zach & Le use η=1/2; η→1 ⇒ touching/standard MM = IRLS)
  • lut_points::Int=128: κ² lookup-table resolution
source
LocalOptimizationDoneRight.BarronAdaptive — Type
BarronAdaptive(; scale_multiple | loss_width, max_iter=25, α_min=-10.0,
               truncation_multiple=10.0, n_sub=256)

Solver-matched ADAPTIVE-SHAPE robust IRLS: the identical PosteriorIrlsMethod/block_coordinate_descent! machinery as StudentTUniform / Irls{WelschShape}, with Barron's generalized loss ρ(r; α, losswidth) (CVPR 2019) whose SHAPE α is re-estimated each iteration from the current residuals by minimizing the truncated-partition negative log-likelihood of Chebrolu et al. (RA-L 2021, Eq. 11-15): 1-D grid search over α ∈ [αmin, 2], with Z̃(α) = ∫_{-T}^{T} e^{-ρ(x, α, 1)} dx, T = truncation_multiple (the normaliser's domain, in units of the loss width). The loss width is scale_multiple·ŝ, frozen at the seed partition's Student-t scale — Chebrolu et al. fix the width for exactly the scale/shape confounding our partition anchor resolves. n_sub caps the residual subsample used by the α grid search (strided; the full set is used when n ≤ n_sub).

This is the "adaptive-static" cell of the loss taxonomy: the loss adapts its shape within the solve (no lift, no graduation) — the strongest representative of "why not adapt instead of lift?".

source
LocalOptimizationDoneRight.BarronAdaptiveLikelihood — Type
BarronAdaptiveLikelihood <: AbstractWeightPolicy

Likelihood adapter for BarronAdaptive. update_nuisance! is the α-step (Chebrolu Alg. 1 step 1): grid-argmin over α of log Z̃(α) + mean ρ(rᵢ/c; α) on the (strided) residual subsample. update_weights! sets the Barron IRLS weights at the current (α, c). Only the SHAPE α moves here; the WIDTH is frozen at construction from the arm's (scale_multiple, ŝ²) pair (sq_loss_width) and is stored as its reciprocal because the unit-scale α math divides by it.

PoseLib truncated refiners

External refiners (VisualGeometryCore's ExternalRefit): they refine a seed at an absolute loss width through refine_external!, outside the RANSAC loop. The solver calls load with PoseLib (a package extension). See Baselines.

LocalOptimizationDoneRight.PoseLibLm — Type
PoseLibLm(max_iter) <: AbstractLocalOptimization

PoseLib Levenberg–Marquardt over the TRUNCATED Sampson loss (TLSShape) — the LO-RANSAC standard truncated refiner (TLS-IRLS). An external refiner (ExternalRefit): it refines at an absolute loss width (refine_external!), not in the native RANSAC loop. max_iter is its LM budget.

LocalOptimizationDoneRight.PoseLibLmAdaptLossWidth — Type
PoseLibLmAdaptLossWidth(; max_iter, rounds, scale_multiple)

Consensus-anchored truncated refit (TLS-IRLS-ŝ): PoseLib LM over the truncated loss, its loss width re-formed between rounds LM rounds as scale_multiple·ŝ of the current model's within-width residual scale (outer pose-block / scale-moment alternation; PoseLib is a black box).

The INITIAL width is anchored on the seed's consensus scale — ŝ² of the consensus set under the refit scoring at the outlier half-width of the delivered loss width (loss_width_to_outlier_halfwidth at the refit protocol's operating scale multiple, [local_optimization.poselib_adapt] operating_scale_multiple), RobustVisualGeometry's consensus_s2! — never a plug-in scale; a consensus too thin to carry a scale makes no refit. max_iter is the total LM budget across rounds. Defaults: configs/default.toml [local_optimization.poselib_adapt]. E-track only (PoseLib refine_relpose).

The E-branch optimizer body of a PoseLib truncated refiner WITHOUT a guard or scoring bracket: the seed's cheirality-resolved pose (fast strided vote on the problem's bearings) refined by PoseLib refine_relpose at the absolute pool-frame loss_width, on the refiner's external_workspace. Cross-validated operating points

LocalOptimizationDoneRight.tuning_constant — Function
tuning_constant(problem::Symbol, shape::AbstractString;
                features::Symbol = :any, dataset::Symbol = :any) -> TuningConstant

Resolve the cross-validated scale_multiple for problem (:essential | :fundmat | :homography | :radial_homography | :radial_camera | :absolute_pose) and loss shape (the tag vocabulary a strategy's loss key uses) along the provenance hierarchy (features, dataset) → (features, :any) → (:any, :any).

shape does NOT wildcard. A scale multiple is an operating point for one shape, not a unit that converts between them, so a class with no entry for the requested shape raises rather than serving a constant validated for a different one. Check .validated to see whether the returned value was cross-validated at its own key or transferred (.transfer names the source key), and .tuning for the product tuning that produced it.

LocalOptimizationDoneRight.TuningConstant — Type
TuningConstant

A cross-validated scale_multiple with codified provenance — the loss width as a multiple of the estimated scale; see VisualGeometryCore.deploy.

Fields

  • scale_multiple::Float64 — the loss width as a multiple of ŝ (partition-anchored).
  • shape::String — the loss shape this value was validated for, in the tag vocabulary a strategy's loss key uses ("welsch", "geman_mcclure", …).
  • tuning::TuningProvenance — the product tuning that produced the value (for a transfer: the one that produced the value it borrows).
  • transfer — nothing for a value validated at its own key, else the registry key (problem, features, dataset) it was transferred from.
  • validated::Bool — transfer === nothing (derived, not stated).
