LocalOptimizationDoneRight.LocalOptimizationDoneRight — Module
LocalOptimizationDoneRight

The local optimizers of the ACCV 2026 paper "Score Sharp, Refine Soft, Polish Hard", on VisualGeometryCore's local-optimization contract and RobustVisualGeometry's problems:

  • the joint-(θ,z) half-quadratic loss lifts (HQ and its research variants WelschHQNewton, WelschHQEcm, BarronHQ, GmHqEps) and graduated non-convexity (Gnc), one code path over VisualGeometryCore's chart-rows contract (the lift core and its continuation schedules live here);
  • the Student-t + uniform IRLS (StudentTUniform), its score-matched block-coordinate ascent (StuTuBCD), the mixture lifts (StuTuHQTabulated, StuTuRegemm) and the Barron-adaptive IRLS (BarronAdaptive);
  • PoseLib's truncated refiners (PoseLibLm, PoseLibLZ, PoseLibLmAdaptLossWidth) as external refiners (their solver calls load with PoseLib, a package extension);
  • the cross-validated operating points (tuning_constant) and the strategies' TOML registry (LO_TAGS), merged with the core's to load: local_optimization_from_toml(d; class, tags = merge(RobustVisualGeometry.LO_TAGS, LO_TAGS)).

Compose one with any scorer: find_essential(cam1, cam2, pairs; local_optimization = HQ{WelschShape}(scale_multiple = WELSCH_HQ_SCALE_MULTIPLE_ESSENTIAL)).
